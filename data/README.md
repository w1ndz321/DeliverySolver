# Data

此目录只保留题目侧提供的原始材料：

| 文件 | 作用 |
| --- | --- |
| `large_seed301.txt` | 唯一公开输入实例，也是 Demo 派生场景的种子。 |
| `example_solution.txt` | 官方/原始参考解法材料。 |
| `info.txt` | 原始题目说明材料。 |

## Demo 场景如何得到

`backend/scenarios.py` 运行时在内存中从 `large_seed301.txt` 生成三类验证输入，不写出任何新数据文件：

| 场景 | 确定性变换 | 验证目的 |
| --- | --- | --- |
| 低意愿压力 | 固定抽取 30 单、保留 60 骑手、按固定随机种子保留 25% 合单边、接单意愿乘 `0.25` | 验证拒单风险上升后的策略改进 |
| 骑手稀缺 | 保留公开实例中按首次出现顺序的前 25% 骑手 | 验证供给不足时的覆盖与损失 |
| 中型约束实例 | 固定抽取 30 单、保留前 30 名骑手 | 防止专项优化损害较一般场景 |

这样既能演示 Agent 的泛化验证思路，也避免把开发阶段生成的大量实验文件包装成原始数据。
