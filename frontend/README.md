# Frontend

前端是不需要构建工具的静态 HTML/CSS/JavaScript，由 `backend/app.py` 同源提供。

## 页面

| 页面 | 作用 |
| --- | --- |
| `index.html` | 项目介绍页：问题、在线/离线闭环方法、运行时验证场景、系统边界和工作台入口。 |
| `demo.html` | 闭环工作台：前端调用在线求解和离线学习 API，展示数据画像、策略评分、诊断、生成候选、最终算法代码和离线生成模块。 |

`app.js` 只展示流程预览与场景定义，不读取预生成分数。`demo.js` 调用 `/api/autosolver/solve`
和 `/api/autosolver/offline`，页面展示的评分、诊断和生成策略都来自后端实时返回。

## 设计原则

- 首屏直接说明“分析 -> 评分 -> 诊断 -> 离线学习”的价值，不将算法跑分包装成虚假的 Agent 能力。
- 工作台必须展示后端证据：策略分数、诊断、在线候选试跑结果、离线生成模块路径。
- 介绍页和 API 保持同源部署；不要仅上传此目录作为静态站点，否则交互实验无法工作。
